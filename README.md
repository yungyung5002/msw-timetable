# MSW 課堂時間表 🗓️

> 一個用 AI 自製、純屬自娛自樂的小工具。歡迎交流、參考、拿去改。

這是一份為 PolyU MSW 課堂設計的流動版時間表，純 HTML/CSS/JS 單檔實作，
可直接裝進手機主畫面離線使用。沒有後台、沒有帳號、沒有收費——就是自己寫來方便自己。

---

## ✨ 功能特點

- **全學期課堂**：按日期排序，每節一張圓角卡片（科目／日期／時間／地點／老師）
- **自動下課**：課堂結束時間過後自動消失，不佔版面
- **歷史課程**：頂部灰色按鈕，隨時回看已完成的課堂
- **功課管理**：新增／編輯／刪除，附截止日與倒數狀態（顏色 `#598987`）
- **課堂編輯**：每張卡片可改日期／時間／地點／老師
- **批量匯入**：貼 CSV、上傳 `.csv`／`.json`，或下載範本填寫
- **學期管理**：Sem 1 → Sem 2 → Summer Term，按日期自動排序；
  某學期最後一節結束後，會彈出確認鍵一鍵清空該學期課堂＋功課
- **PWA 安裝**：支援 iOS「加到主畫面」與 Android「安裝」，離線可看

## 🛠 技術堆疊

- 單一 `index.html`（無框架、無建置步驟）
- `localStorage` 儲存所有資料（資料只存在你自己裝置上）
- PWA：`manifest.webmanifest` + `sw.js` 離線快取 + `apple-touch-icon`

## 🚀 使用方式

**手機直接開**

1. 把本倉庫檔案部署到任意靜態空間（例如 GitHub Pages）
2. iPhone：Safari 開啟網址 → 分享 →「加到主畫面」
3. Android：Chrome 開啟 → 選單 →「安裝應用程式」

**本地預覽**

直接雙擊 `index.html` 即可，資料會存在瀏覽器本機。
